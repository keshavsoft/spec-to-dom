How to Use spec-to-dom

Get up and running with spec-to-dom in under two minutes. Learn how to install, import, and configure DOM mount operations across all application environments.

1. Installation

Choose your preferred installation or loading method:

Option A: NPM Package (Recommended for Bundlers)

Terminal 
npm install spec-to-dom

Option B: PNPM or Yarn

Terminal 
pnpm add spec-to-dom
# or
yarn add spec-to-dom

Option C: Direct CDN / ES Module

In vanilla HTML or standalone prototypes, import directly without a build step:

HTML Script Tag 
<script type="module">
  import appendToDom from "https://cdn.jsdelivr.net/npm/spec-to-dom@1.2.1/src/index.js";
  
  const heading = document.createElement("h1");
  heading.textContent = "Mounted via CDN!";
  
  appendToDom({
    buildSpec: heading,
    targetHtmlId: "app"
  });
</script>

2. API Reference: appendToDom()

The primary export of the library is appendToDom. It accepts a single structured configuration object:

JavaScript Signature 
import appendToDom from "spec-to-dom";

const mountedContainer = appendToDom({
  buildSpec,        // HTMLElement | Array | NodeList | HTMLCollection
  targetHtmlId,     // string (HTML ID of the container element)
  appendPosition,   // "append" | "prepend" (optional, default: "append")
  showLog           // boolean (optional, default: false)
});

3. Parameters Breakdown

Property Type Default Description
buildSpec Node | Node[] | Collection Required The DOM node, array of nodes, or collection to attach into the target container.
targetHtmlId string Required The HTML id string of the destination container in your document.
appendPosition "append" | "prepend" "append" When set to "prepend", inserts items before existing children. For single elements with "append", replaces container content.
showLog boolean false When true, logs debug output to the browser console during execution.

Return Value

Returns the resolved HTMLElement container if mounting succeeds, or null if no matching element with targetHtmlId was found in the DOM.

4. Step-by-Step Usage Guide

Step 1: Define Target HTML Container

index.html 
<!-- Destination container -->
<div id="notification-feed" class="p-4 border rounded"></div>

Step 2: Mount Elements Dynamically

main.js 
import appendToDom from "spec-to-dom";

// Construct an element
const alertBox = document.createElement("div");
alertBox.className = "alert alert-success";
alertBox.textContent = "Data synced successfully!";

// Mount to the container
appendToDom({
  buildSpec: alertBox,
  targetHtmlId: "notification-feed",
  appendPosition: "prepend",
  showLog: true
});

5. Global Registration: window.ks.specToDom

When imported or loaded in the browser, spec-to-dom automatically registers itself under the global KeshavSoft namespace:

Browser Global Access 
// Inspect registered global metadata
console.log(window.ks.specToDom.meta);
// Output: { version: "1.2.1", name: "spec-to-dom" }

// Call directly from any script or console
window.ks.specToDom.appendToDom({
  buildSpec: myElement,
  targetHtmlId: "app"
});
