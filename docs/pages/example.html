Practical Examples

Explore functional use-cases showing how spec-to-dom handles collections, prepending items, and building responsive browser user interfaces.

Example 1: Dynamic Data Table Rows

Mounting multiple table rows simultaneously without re-rendering the whole table header or triggering expensive re-layouts:

dynamic-table.js 
import appendToDom from "spec-to-dom";

// 1. Data array from API
const users = [
  { id: 101, name: "Alice Morgan", role: "Lead Architect", status: "Active" },
  { id: 102, name: "Bob Vance", role: "DevOps Engineer", status: "Pending" },
  { id: 103, name: "Carol Danvers", role: "Security Specialist", status: "Active" }
];

// 2. Generate array of HTMLTableRowElements
const rowElements = users.map(user => {
  const tr = document.createElement("tr");
  tr.innerHTML = `
    <td>#${user.id}</td>
    <td><strong>${user.name}</strong></td>
    <td>${user.role}</td>
    <td><span class="badge">${user.status}</span></td>
  `;
  return tr;
});

// 3. Batch mount directly into tbody using spec-to-dom
appendToDom({
  buildSpec: rowElements,
  targetHtmlId: "users-table-body",
  appendPosition: "append"
});

Example 2: Prepending Real-Time Live Feed

In messaging apps, audit logs, and notification feeds, new items should appear at the top. Set appendPosition: "prepend" to place new nodes first instantly:

prepend-feed.js 
import appendToDom from "spec-to-dom";

function onNewNotification(notification) {
  const item = document.createElement("div");
  item.className = "demo-item notification";
  item.innerHTML = `
    <span>🔔 <strong>${notification.title}:</strong> ${notification.message}</span>
    <small style="color:var(--text-muted);">Just now</small>
  `;

  // Prepend to top of notification container
  appendToDom({
    buildSpec: item,
    targetHtmlId: "feed-container",
    appendPosition: "prepend"
  });
}

Example 3: Dynamic Form Card Builder

Construct complex UI widgets and mount them cleanly with automatic container replacement:

form-builder.js 
import appendToDom from "spec-to-dom";

const formCard = document.createElement("div");
formCard.className = "p-4 border rounded shadow-sm bg-white";
formCard.innerHTML = `
  <h3 style="margin-bottom:0.75rem;">Project Settings</h3>
  <div style="margin-bottom:1rem;">
    <label style="display:block; font-size:0.85rem; font-weight:600; margin-bottom:0.25rem;">Project Name</label>
    <input type="text" value="spec-to-dom v1.2.1" style="width:100%; padding:0.5rem; border:1px solid #cbd5e1; border-radius:4px;" />
  </div>
  <button type="button" class="btn btn-primary">Save Configuration</button>
`;

appendToDom({
  buildSpec: formCard,
  targetHtmlId: "form-slot",
  showLog: true
});

Example 4: Synergy with Custom Elements & Web Components

spec-to-dom pairs seamlessly with custom element lifecycle callbacks:

custom-widget.js 
import appendToDom from "spec-to-dom";

class MetricsWidget extends HTMLElement {
  connectedCallback() {
    this.innerHTML = `<div id="metric-content"></div>`;
    
    const metricBadge = document.createElement("span");
    metricBadge.className = "badge-item";
    metricBadge.textContent = "Telemetry Online";

    appendToDom({
      buildSpec: metricBadge,
      targetHtmlId: "metric-content"
    });
  }
}

customElements.define("metrics-widget", MetricsWidget);
