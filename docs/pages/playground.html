Click any button below to trigger dynamic DOM mounting via appendToDom():

Execution Snippet 
import { appendToDom } from "spec-to-dom";

// 1. Mount single node (replaces container contents)
appendToDom({
  buildSpec: cardElement,
  targetHtmlId: "live-demo-target"
});

// 2. Prepend live stream event
appendToDom({
  buildSpec: alertElement,
  targetHtmlId: "live-demo-target",
  appendPosition: "prepend"
});

// 3. Append collection array
appendToDom({
  buildSpec: [item1, item2],
  targetHtmlId: "live-demo-target",
  appendPosition: "append"
});
